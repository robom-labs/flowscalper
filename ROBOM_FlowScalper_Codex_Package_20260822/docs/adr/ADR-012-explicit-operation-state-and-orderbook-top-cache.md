# ADR-012. 시작 상태 가시화·자동 안전복귀·상위 호가 캐시

## 결정

1. 초보자 시장 화면은 `시작 전`, `연결 중`, `작동 중`, `사용자가 일시정지`, `작동 중 · 안전 대기`, `작동 중 · 안전 확인 필요`, `시장 다시 연결 중`을 서로 다른 상태로 표시한다.
2. 시장 관찰과 새 PAPER 진입을 별도 항목으로 표시한다. 안전잠금 중에도 공개시장 supervisor가 계속 관찰 중이면 프로그램 전체를 `멈춤`으로 표현하지 않는다.
3. 임계 지연·연결·저장공간처럼 자동 회복 가능한 잠금은 사용자의 반복 재개 클릭을 요구하지 않는다. 정상 sequence-valid 공개호가와 기존 안전조건이 돌아오면 새 PAPER 진입을 자동 복귀한다.
4. 사용자가 직접 누른 일시정지만 `새 진입 다시 시작` 버튼으로 해제한다. 저장 실패와 복구 불일치처럼 자동 해제가 안전하지 않은 잠금은 별도 확인 필요 상태로 남긴다.
5. 로컬 주문장은 전체 1,000단계 가격을 보존하되 상위 20단계 가격을 캐시한다. 수량 변경과 비상위 가격 변경은 작은 후보 집합만 갱신하고, 캐시 가격이 삭제될 때만 전체 가격 순서를 다시 계산한다.

## 이유

기존 화면의 `paused` 한 값은 사용자가 멈춘 상태와 지연 안전잠금을 같은 `새 진입 멈춤`으로 표시했다. 실제 supervisor가 계속 시장을 받는 중에도 사용자는 시작 버튼이 무반응이거나 프로그램이 혼자 종료된 것으로 이해할 수 있었다.

또 실제 8870 장시간 Run은 처리지연 p95 7,352ms와 CPU 65.685% 상태에서 안전잠금이 유지됐다. macOS 표본은 Decimal 비교와 전체 호가 정렬을 반복 병목으로 표시했다. 기존 `top(20)`은 모든 depth delta마다 양쪽 1,000단계를 다시 정렬했다.

## 불변조건

- 상위 호가 캐시는 기존 전체 정렬과 가격·수량·순서가 정확히 같아야 한다.
- 캐시가 불확실해지는 상위 가격 삭제 시 전체 원장을 기준으로 다시 계산한다.
- 임계 지연 1,500ms 기준과 전략·비용·지연·위험 조건은 낮추지 않는다.
- 자동 복귀는 시장·저장·복구 안전조건이 모두 충족될 때만 가능하다.
- 실제 주문, private API, 인증 header, API Key, secret, wallet 경로는 계속 0이다.

## 검증

- 1,000단계 주문장 10,000회 상위 20단계 조회 benchmark에서 전체 정렬 0.275076초, 캐시 0.010393초로 같은 결과를 유지하며 약 26.47배 빨라졌다.
- 임계 지연 잠금·자동 회복·사용자 일시정지를 runtime dashboard 계약과 frontend 제어 테스트로 각각 검증한다.
- 실제 8870 브라우저에서 `자동 관찰 시작` 한 번으로 `연결 중`을 거쳐 `작동 중`이 됐고, 일시정지·재시작도 각 한 번의 클릭으로 전환됐다.
- 6시간·24시간 실행은 이 결정 검증에서 `NOT_RUN`이다.
