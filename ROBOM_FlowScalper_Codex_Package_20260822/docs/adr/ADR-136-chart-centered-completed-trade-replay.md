# ADR-136 완료 거래 중심 차트 다시보기

- 상태: 채택
- 적용 Wave: 146
- 범위: 공개시장 데이터로 완료된 PAPER 거래의 사용자 다시보기

## 배경

기존 `과거 재생`은 저장 Run 전체를 먼저 고른 뒤 정밀 이벤트를 별도로 불러오는 진단 흐름이었다.
사용자가 특정 완료 거래를 다시 볼 때도 차트보다 Run 선택과 원시 진단이 먼저 보였고, 실제 진입 전
흐름·진입·초기 TP1·TP2·SL·실제 종료를 한 화면에서 시간순으로 이해하기 어려웠다.

## 결정

1. `거래 > 다시보기`의 기본 화면은 완료된 `LIVE_PUBLIC` PAPER 거래 기회 목록과 선택한 거래의
   차트를 함께 보여 준다. 최신 거래를 위에 두고 데스크톱은 목록과 차트를 나란히, 좁은 화면은
   차트를 우선한 세로 배치로 바꾼다.
2. 같은 진입기회의 BASE·STRESS 또는 계좌별 원장 행은 삭제하거나 합치지 않는다. 시각 목록에서만
   BASE와 공동 MAIN을 우선해 한 번 표시하고 원시 행은 기존 원장과 상세 API에 보존한다.
3. 재생은 신호 이전의 완성 캔들부터 시작한다. 신호 전에는 진입·TP·SL 계획선을 숨기고, 재생
   시각이 신호·실제 체결·TP1·TP2·실제 종료에 도달할 때만 해당 표시를 누적한다.
4. 진행 시각에 아직 마감되지 않은 캔들은 표시하지 않는다. 캔들 open 시각이 아니라
   `open + interval`을 기준으로 노출해 미래 OHLC가 보이는 look-ahead를 막는다.
5. 진입 설명은 저장된 후보의 reason code와 당시 regime를 근거로 쉬운 한국어로 표시한다.
   Registry의 이름·설명·필수 시간구간은 보조 설명이며 거래의 저장 전략 버전과 현재 Registry
   버전이 다르면 그 사실을 고급 진단에 명시한다.
6. 초기 손절선은 계획선으로 유지한다. `STOP_HIT` 종료 표시는 초기 손절 가격으로 바꾸지 않고
   원장에 저장된 실제 종료 가격과 시각을 사용한다. TP1·TP2 표시는 저장된 도달 상태 또는 실제
   종료 근거가 있을 때만 나타낸다.
7. 속도, 처음부터, 이전·다음, 신호·실제 진입·TP1·TP2·실제 종료 이동을 하나의 플레이어에 둔다.
   정확한 KST 진입·종료 시각과 보유시간, 종료 이유, 비용후 결과를 차트 아래에 표시한다.
8. 저장 Run 전체를 검사하는 기존 진단 재생은 삭제하지 않고 접힌 `고급 Run 진단`으로 분리한다.
   완료 거래 목록은 다시보기 탭이 열렸을 때만 조회·갱신해 정상 거래기록 화면의 읽기 부하를
   늘리지 않는다.

## 결과와 한계

- 초보 사용자는 거래 한 건을 선택한 뒤 영상처럼 재생하며 진입 전후와 실제 종료를 볼 수 있다.
- 표시가 쉬워져도 저장된 시장 이벤트가 없거나 불완전한 과거 거래는 재생할 수 없다.
- 현재 Registry 설명은 과거 거래 당시 전략 정의의 증거가 아니다. 버전이 일치하지 않으면
  `현재 설명 참고용`으로만 표시한다.
- 화면과 테스트 통과는 전략의 비용후 수익성 증거가 아니다. 수익성은 계속 `NOT_PROVEN`이다.
