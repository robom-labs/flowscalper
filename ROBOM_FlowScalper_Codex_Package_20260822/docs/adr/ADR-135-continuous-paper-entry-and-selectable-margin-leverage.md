# ADR-135 연속 PAPER 진입과 선택형 증거금 배수

## 상태

Accepted.

## 배경

현재 프로그램은 실제 주문이 전혀 없는 공개시장 PAPER 연구 도구지만 하루 거래횟수, 하루·주간
손실과 연속손실 cooldown이 실계좌용 정지장치처럼 신규 진입을 막을 수 있었다. 사용자는 정상
실행이면 별도 시작·재개 조작 없이 모든 현재 연구전략을 계속 비교하고, PAPER 레버리지를 기본
10배에서 최대 100배까지 선택하기를 요청했다.

레버리지를 단순히 수량 배수로 적용하면 stop 기준 계획손실과 실제 호가깊이를 무시하고 가짜
체결·가짜 성과를 만들 수 있다. 따라서 연속 연구를 막는 기간 quota와 시뮬레이션의 신뢰성을
지키는 위험·데이터 안전경계를 분리해야 한다.

## 결정

1. 실제 LIVE PAPER 런타임의 공동계좌와 Strategy League 모두에서 하루 거래횟수, 하루 손실,
   주간 손실과 연속손실 cooldown을 신규 진입 거절 사유로 사용하지 않는다. 계측값과 과거
   기록은 삭제하지 않는다.
2. peak 대비 drawdown, 계좌별 동시 포지션, 총 계획손실, 실제 실행가능 호가깊이, 비용후
   손익비, 데이터 지연·gap, 저장·복구·원장 fault는 계속 fail-closed한다.
3. PAPER 증거금 배수는 1·2·3·5·10·20·25·50·75·100배 중 선택하며 기본은 10배다.
4. 수량은 기존 stop·양방향 수수료·예상 슬리피지·계획손실·호가깊이로 정한다. 선택 배수는
   `PAPER 증거금 = 실제 진입 명목금액 ÷ 선택 배수` 계산에 사용하고 계좌 총 명목금액 상한도
   선택 배수와 맞춘다.
5. 수수료, 슬리피지와 손익은 실제 PAPER fill 명목금액으로 계산한다. 100배를 골라도 모든
   주문을 강제로 자산의 100배로 만들지 않는다.
6. 설정은 전역 SQLite app setting에 revision과 함께 저장한다. CAS 충돌은 409로 반환하고,
   허용 목록 밖의 값은 거부한다. 변경은 새 진입부터 적용하고 열린 포지션과 완료 거래는
   진입 당시 배수·명목금액·증거금을 보존한다.
7. 정상 사용자 화면에서 일상적인 진입 일시정지·재개 버튼을 제거한다. 일반 사용자 pause가
   과거 원장에 남아 있으면 다음 정상 재시작에서 `ENTRY_ENABLED`로 복구한다. 배포 유지관리
   사유의 pause는 설치 중 Run 보호를 위해 유지하고 배포 절차가 명시적으로 해제한다.
8. 화면은 `자동 진입 · 항상 허용`과 `자동 진입 · 안전 대기`를 구분한다. 안전대기는 거래량을
   억지로 만들기 위한 제한이 아니라 검증할 수 없는 체결을 막는 상태다.
9. 실제 주문, private API, API Key, secret, wallet, 입출금과 runtime AI 주문판단은 계속 0이다.

## 검증 계약

- 기간 quota와 cooldown 값이 이미 한도를 넘은 상태에서도 해당 reason code 없이 진입 검사를
  통과하는 단위 회귀를 둔다. drawdown과 시스템 fault 회귀는 계속 통과해야 한다.
- 10배 진입의 실제 명목금액, `명목금액 ÷ 10` 증거금, 실제 명목금액 수수료와 기존 계획손실
  상한을 하나의 종단 PAPER 체결 회귀로 확인한다.
- 설정 API의 100배 적용, revision 충돌, 허용되지 않은 7배 거부, SQLite 복구를 확인한다.
- 일반 pause는 정상 재시작에서 자동복구되고 배포 유지관리 pause는 유지되는 회귀를 분리한다.
- 실제 브라우저에서 설정 변경, 상단 자동진입 상태, 포지션의 진입 당시 배수·증거금과 실제주문
  0을 확인한다.
- 짧은 실행·거래 증가·높은 배수는 수익성 증거가 아니다. 6시간·24시간과 비용후 성과 gate는
  실제 실행 전까지 각각 `NOT_RUN`, `NOT_PROVEN`으로 남긴다.

## 결과와 한계

연속 PAPER 표본 수집은 기간별 정지장치 때문에 멈추지 않는다. 그러나 시장 조건을 충족하지
않으면 신규 거래가 0일 수 있으며, 이를 오류로 오인해 전략 기준·비용·TP·SL·호가 안전기준을
낮추지 않는다. 최대 100배 선택은 연구 표시와 증거금 비교 기능이지 수익을 보장하거나 실자금
준비상태를 의미하지 않는다.
