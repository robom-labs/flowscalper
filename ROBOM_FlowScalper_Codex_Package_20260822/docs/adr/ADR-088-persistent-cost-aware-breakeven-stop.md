# ADR-088. 순간 고점이 아닌 지속 가격으로 본전 손절선을 활성화한다

## 상태

Accepted, 2026-08-29.

## 문제

과거 `STRATEGY_100_SCREENING_TRADES.jsonl` 77행을 다시 검사했다. 독립된
`signal_event_id`는 14개뿐이고 46행이 15초 이내, 6행이 3초 이내에 종료됐다. 3초 이하
6행은 종료안 E03~E05에 중복된 실제 시장기회 2개였다. 한 기회는 초기 손절가를 실제로
통과했다. 다른 F19 LONG 기회는 2.802초 동안 MFE +1.071R, MAE -0.071R이었지만
`breakeven_tighten_r=1.0`을 순간 통과한 직후 본전 손절선이 즉시 올라가 `STOP`으로
종료됐다. 세 종료안의 BASE 원장 행은 각각 비용후 -50.749bp였다.

일반 이익보호 청산은 복수 불리 근거와 3초 지속을 요구하지만, 공통
`PositionManager._profit_protection_stop`의 본전 손절선 조정에는 지속시간과 현재가격
확인이 없었다. 과거 최고가인 MFE만 1R을 넘으면 현재가격이 이미 되밀린 뒤에도 손절선을
올릴 수 있었다. 고정 13bp만 사용해 계획 왕복비용 R이 더 큰 경우도 보호하지 못했다.

## 결정

1. 본전 손절선은 활성화 기준을 처음 충족한 뒤 3,000ms 동안 연속 확인되기 전에는 조이지
   않는다.
2. 과거 MFE뿐 아니라 실행 가능한 현재가격의 `current_r`도 활성화 기준 이상이어야 한다.
   현재가격이 기준 아래로 되밀리면 3,000ms 확인을 처음부터 다시 시작한다.
3. 활성화 기준은 `max(1.0R, 계획 왕복비용 R)`이다. 따라서 계획비용보다 작은 순간
   이익으로 비용보호 손절선을 만들지 않는다.
4. 보호가격 거리는 고정 13bp와 `초기 가격위험 × 계획 왕복비용 R` 중 큰 값을 사용한다.
5. 초기 SL·TP1·TP2, 데이터·시스템 안전종료, 일반 이익보호의 복수근거·3초 지속 계약은
   바꾸지 않는다. 신호기준·포지션 크기·TP·SL을 완화해 거래를 만들지 않는다.
6. 과거 77행은 변경하거나 삭제하지 않는다. 새 정책의 실제 자연표본은 새 전략 개정에서
   다시 모으고, 30개 고유 시장기회 전에는 승률 순위를 매기지 않는다.

## 검증

- +1.1R이 2,999ms 지속됐을 때는 본전 손절선을 조이지 않는다.
- +1.1R이 3,000ms 연속 지속되고 MFE와 현재가격이 모두 기준을 충족할 때만 조인다.
- 확인 중 현재가격이 기준 아래로 내려가면 지속시간을 초기화한다.
- 과거 MFE가 +1.1R이어도 현재가격이 +0.1R이면 손절선을 조이지 않는다.
- 계획 왕복비용이 고정 13bp보다 크면 계획비용을 우선한다.
- 계획 왕복비용 R이 현재 유리한 이동보다 크면 조이지 않는다.
- LONG·SHORT 손절선 확대 금지와 기존 관리청산 회귀를 함께 실행한다.

## 한계

이 결정은 순간 고점 뒤 비용만 확정하는 짧은 PAPER 종료 경로를 차단하는 회귀 수정이다.
승률 또는 수익성 향상을 증명하지 않는다. 과거 100개 실험은 계좌별 완료거래가 최대
4건이고 검증 표본 30건을 충족한 계좌가 0개이므로 전략 선택 근거로 사용할 수 없다.
