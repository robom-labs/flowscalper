# ADR-122. 4시간 추세 실패는 보존하고 일봉 후보에 시간순 안정성 gate를 추가한다

- 상태. 채택
- 범위. HYP-127 결과 판정과 후속 HYP-128 PAPER 연구
- 제외. 실제 주문, private API, 실자금 승격, 결과 뒤 HYP-127 임계값 변경

## 문제

사용자 목표에 맞춰 인터넷·논문 기반 추세 가설을 빠르게 많이 평가하더라도 후보 수만 늘리면
Train·Validation 우연을 고르는 다중검정 위험도 함께 커진다. HYP-127의 다년 4시간 30후보에서
이 문제가 실제로 드러났다. Train·Validation에서 통과한 3계열은 진단 OOS에서 모두 BASE와
STRESS 기대값이 음수였고 PBO는 0.60이었다.

실패를 삭제하고 같은 데이터에서 임계값만 미세조정하면 과거에 맞는 숫자는 만들 수 있지만 독립
미래 성과는 더 약해진다. 반대로 실패 때문에 전략 기준을 낮춰 거래를 늘리거나 실전 후보로
승격하는 것도 PAPER 연구 목적과 맞지 않는다.

## 결정

1. HYP-127의 전체 결과, 후보·데이터·구현·비용 지문과 trial record를 append-only로 보존한다.
2. HYP-127의 30개 후보 중 Registry 또는 SHADOW로 승격하는 후보는 0개다.
3. 같은 4시간 후보 ID의 임계값을 결과 뒤 수정하지 않는다.
4. 후속 HYP-128은 완성 4시간봉 여섯 개로 만든 UTC 일봉만 사용해 신호대 잡음과 회전을 낮춘다.
5. HYP-128은 일봉 채널·재시험·초입 첫 눌림·일목·EMA 눌림 5계열을 롱·숏·양방향과 두 강도로
   고정한 30개 별도 후보로 사전등록한다.
6. 기존 50% Train·20% Validation gate 전에 development 70%를 6개 연속 fold로 나눈다.
7. fold당 STRESS 완료거래 8개, 평가 가능 5개 fold, 양수 4개 fold, 최신 두 fold 양수를 모두
   요구한다. 통과 후보만 최대 한 계열당 하나씩 OOS로 보낸다.
8. BASE 13bp·STRESS 25bp와 실제 방향별 펀딩, 다음 일봉 시가 진입, 같은 일봉 손절 우선,
   미결 포지션 미채점 계약을 유지한다.
9. HYP-128도 HYP-127 결과를 본 뒤 만든 적응 연구이므로 역사 통과를 독립 OOS나 수익성
   입증으로 부르지 않는다.
10. 실제 bid·ask SHADOW 자연표본과 새 미래구간 전에는 `NOT_PROVEN`, `NOT_READY`를 유지한다.

## HYP-127 결과

- 공개 완성 4시간봉 148,824개와 펀딩 74,487개를 사용했다.
- Train·Validation에서 돌파 재시험 롱, 채널 돌파 양방향, 일목 눌림 롱 3개를 선택했다.
- 진단 OOS BASE 기대값은 각각 -61.299bp, -27.397bp, -201.675bp였다.
- 진단 OOS STRESS 기대값은 각각 -73.299bp, -39.397bp, -213.675bp였다.
- 표본은 각각 27, 35, 47건이고 승률은 29.63%, 37.14%, 42.55%였다.
- 세 후보 모두 PF·bootstrap·DSR·PBO 등 전체 gate를 통과하지 못했다.
- 후보 전체 실제 펀딩 적용 cashflow 합계는 -83,465.766bp였으며 모호한 유리한 경계 credit
  1,268.664bp는 제외했다.

## 수용기준

- HYP-127 결과 파일과 trial history가 Git에 보존된다.
- HYP-127 Registry·SHADOW 승격은 0이다.
- HYP-128 코드는 결과 실행 전 후보 지문과 함께 commit된다.
- 일봉 누락·미연속 봉은 집계에서 제외된다.
- 다음 일봉 진입, 손절 우선, 펀딩 경계, walk-forward 최신 fold, 계열 중복 방지 테스트가
  통과한다.
- HYP-128 결과가 실패하면 그대로 보존하고 같은 ID를 재조정하지 않는다.
- 실제 주문·인증·private API·API Key·wallet은 계속 0이다.
