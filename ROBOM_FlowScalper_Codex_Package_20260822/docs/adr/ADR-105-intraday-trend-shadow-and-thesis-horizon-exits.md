# ADR-105. 완성봉 추세 SHADOW와 TP·SL 결판 청산

- 상태. 채택.
- 일자. 2026-08-30.
- 범위. 공개시장 입력을 사용하는 PAPER 연구만 해당한다.

> 후속 현재 상태. ADR-V6에서 current entry variant를 6개로 줄였고, ADR-138에서
> 이 네 전략의 고정 R 배수 TP를 완성봉 구조 목표와 TP1 후 ATR runner로 교체했다.
> 아래는 2026-08-30 당시의 채택 이력으로 보존한다.

## 배경

기존 미시구조 전략의 900초 최대보유와 일반 `EDGE_DECAY` 정책을 15분·30분 추세 전략에 그대로 적용하면, 완성봉에서 확인한 추세 논리가 아직 끝나지 않았는데 초단기 흐름 변화만으로 비용을 확정할 수 있다. 신규 전략은 진입 전에 구조 손절과 TP1·TP2를 확정하므로 정상 시장에서는 시간이 지났다는 이유로 별도 결론을 만들 필요가 없다. 데이터 결손과 복구 이상은 일반 시간청산이 아니라 기존 시스템 안전종료 경로에서 따로 처리한다.

사용자는 상승·하락 초입, 돌파 뒤 재확인, 추세 중 눌림 뒤 재합류를 서로 다른 전략으로 동시에 시험하고, 진입 전에 손절과 익절의 근거를 고정하기를 요청했다. 이미 비용후 재현에 실패한 전략을 다시 켜거나 기록을 삭제해 전략 수만 늘리는 방식은 연구 이력을 훼손한다.

## 결정

1. 다음 네 전략을 신규 V2 SHADOW PAPER 가설로 등록한다.
   - `TREND_PULLBACK_RECLAIM_15M_V2`.
   - `BREAKOUT_RETEST_15M_V2`.
   - `BREAKOUT_RETEST_30M_V2`.
   - `MULTISPEED_TREND_RECLAIM_30M_V2`.
2. 네 전략은 진행 중 봉을 사용하지 않고 완성 15분·30분·1시간 봉만 쓴다. 새 완성봉 신호 뒤 5초 이내의 sequence-valid 공개 bid·ask, OFI, aggressor 체결과 microprice가 1초 이상 같은 방향일 때만 계획을 만든다.
3. 진입 전에 실제 반대호가, 구조 손절, TP1, TP2, 수량, 최대계획손실, BASE·STRESS 비용과 순손익비를 고정한다. 구조 손절은 0.65~3.0 ATR 범위여야 하고 손절은 넓히지 않는다.
4. 네 전략은 일반 미시구조 `EDGE_DECAY` 청산을 사용하지 않는다. 초기 구조 손절, TP1·TP2, 손절의 이익보호 방향 단축, 데이터·시스템 안전종료만 정상 관리경로로 둔다.
5. 네 전략은 `maximum_holding_ms=null`로 계획·복구하며 시간만으로 `MAX_HOLD`를 만들지 않는다. 900초뿐 아니라 8~18시간 임의 백스톱도 정상 청산경로에서 제거한다. TP1·TP2, 구조 손절, 손절의 이익보호 방향 단축으로 결판내며 데이터·시스템 안전종료는 별도 유지한다.
6. 기존 6개 검증 중 SHADOW와 신규 4개를 합쳐 10개를 같은 공개시장 입력에서 동시에 평가한다. 기존 실패 5개는 `RETIRED/OFF`로 유지하되 소스, 독립 BASE·STRESS 계좌, 거래와 판단 근거를 삭제하지 않는다.
7. 모든 신규 전략은 LONG·SHORT, BASE·STRESS를 독립 평가한다. 실제 주문, private API, 인증, API Key, secret, wallet 경로는 추가하지 않는다.
8. 현재 버전 자연 `LIVE_PUBLIC` 30개 고유 기회 전에는 순위를 매기지 않는다. BASE·STRESS 비용후 기대값, Profit Factor, drawdown, 시간순 OOS, bootstrap 하한, DSR, PBO와 집중도 gate 전에는 승격하지 않는다.

## V1과의 차이

이름만 바꾼 V1 재시도가 아니다. 이전 추세 후보는 완성 돌파를 직접 추격하거나 과거 시간봉 신호만 평가했다. V2는 돌파 다음 완성봉의 지지·저항 재확인 또는 EMA20 눌림 뒤 이전 고저 회복을 요구하고, 그 뒤 현재 공개 주문흐름 확인을 별도로 요구한다. 파라미터와 데이터 cutoff는 미래 관찰 전에 사전등록한다.

## 기각한 대안

- 모든 기존 초단기 전략의 최대보유까지 한꺼번에 없애는 안은 해당 전략의 기존 안전계약과 표본을 바꾸므로 기각한다. 이번 결정은 신규 L~O에만 적용한다.
- 거래 수를 늘리기 위해 신호, spread, 비용, 수량 또는 손익비 gate를 낮추는 안은 기각한다.
- 과거 실패 전략을 기록 없이 삭제하거나 다시 기본 활성화하는 안은 선택편향과 회귀를 숨기므로 기각한다.
- 여러 미세 파라미터 변형을 동시에 추가하는 안은 다중시험 부담과 LIVE 처리지연을 늘려 이번 wave에서 기각한다.

## 결과와 검증 경계

- Registry는 15개 전략·30개 독립 계좌를 보유하고, 10개 SHADOW 전략·20개 평가경로가 동시에 실행된다.
- 신규 전략은 일반 근거약화나 경과시간으로 닫히지 않고, 구조 손절·TP와 데이터·시스템 안전종료만 계속 작동한다.
- 신규 후보 수가 늘어도 공개시장 처리 P50·P95, queue, 500ms 초과, drop, gap, persistence fault를 실제 설치 서비스에서 다시 측정한다.
- 단위·통합·replay PASS는 수익성 증거가 아니다. 6시간·24시간과 충분한 미래 자연표본을 실제로 채우기 전에는 `NOT_RUN` 또는 `NOT_PROVEN`을 유지한다.
