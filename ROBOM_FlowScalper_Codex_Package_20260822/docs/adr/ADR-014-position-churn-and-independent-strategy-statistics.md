# ADR-014. 초단기 근거약화 종료 억제와 독립 전략 통계

## 상태

Accepted, 2026-08-24.

## 문제

실제 공개시장 PAPER Run `run-2d24583436d9`의 공동계좌 완료 거래 4건은 보유시간이 각각 1,696ms, 1,518ms, 1,872ms, 5,396ms였고 종료 사유가 모두 `EDGE_DECAY`였다. 초기 손절이나 목표가 도달이 아니었으며, 순손익 합계 -0.43407286392 USDT 중 수수료 0.32237266392 USDT와 슬리피지 0.051771 USDT가 큰 비중을 차지했다.

기존 `PositionManager`는 진입 직후 유예 없이 단 하나의 불리한 건강 신호가 800ms 지속되면 종료를 준비했다. 체결 직후 호가·흐름의 정상적인 흔들림도 진입 가설 붕괴로 취급할 수 있어 비용만 반복해서 부담하는 churn이 발생했다.

또한 전략 성과는 공동계좌 거래와 같은 전략의 BASE/STRESS 독립계좌 거래를 합쳤다. 하나의 후보가 공동계좌와 독립계좌에 함께 배포되면 전략 표본 수, 승률과 기대값이 중복 집계됐다.

## 결정

1. 초기 SL, TP1, TP2, 데이터 안전대기와 15분 비상 stale 종료는 기존 우선순위와 즉시성을 유지한다.
2. 일반 `EDGE_DECAY` 종료는 체결 뒤 10초 동안 유예한다. 유예 중에도 초기 SL과 TP는 그대로 실행된다.
3. 유예 뒤에는 서로 다른 불리한 건강 신호가 최소 2개 동시에 존재해야 한다.
4. 복수 불리 신호는 실제 event time으로 3,000ms 연속 유지돼야 종료한다. 한 신호만 남거나 회복되면 확인시각을 초기화한다.
5. MFE가 +0.8R 이상이면 이익 보호를 위해 10초 유예는 생략할 수 있지만, 복수 신호와 3,000ms 지속 확인은 유지한다.
6. 전략·프로필 및 전략·종목 성과는 Strategy League 독립계좌의 실제 공개시장 `shadow_trades`만 집계한다. 공동계좌와 오프라인 fixture 거래는 별도 공동계좌 자산곡선·거래기록·DEMO 화면에만 사용한다.
7. 모든 전략이 기본으로 켜졌다는 뜻은 A/B `ACTIVE`, C/D/E/F `SHADOW`, 전 전략 LONG·SHORT 허용이다. C~F를 공동계좌 `ACTIVE`로 자동 승격하지 않는다.
8. SQLite와 계산 내부 Decimal 정밀도는 바꾸지 않는다. UI만 자산 2자리, 손익·비용·가격·수량은 크기별 유효 자릿수로 표시한다.
9. 기존 불변 거래 원장은 삭제하거나 수정하지 않는다. 정책 변경 뒤 새 Run에서 이후 거래를 구분한다.

## 검증

- 1~2초의 복수 불리 신호가 일반 근거약화 종료를 만들지 않는지 검증한다.
- 10초 유예 뒤 복수 신호가 3초 지속될 때만 13초 이후 종료하는지 검증한다.
- 단일 `FLOW_DECAY`는 장시간 지속돼도 일반 근거약화 종료를 만들지 않는지 검증한다.
- A~F × LONG/SHORT × TP/STOP 24개 시나리오에서 초기 보호주문과 즉시 손절 경로가 유지되는지 검증한다.
- 공동계좌 거래 1건과 같은 전략의 BASE 거래 1건을 함께 저장해도 전략 표본이 1건인지 검증한다.
- 승·패·보합, Wilson 95% 범위, 기대값, Profit Factor, 비용, 낙폭과 보유시간을 독립계좌 화면에서 확인한다.

## 한계

이 정책은 명백한 1~2초 churn 결함을 줄이지만 수익성을 보장하지 않는다. 자연 공개시장 신호의 이후 보유시간 분포와 전략별 승률은 새 Run에서 충분한 완료 표본을 수집해야 판단할 수 있다. 최소 30건 전에는 계속 `표본 부족`으로 표시한다.
