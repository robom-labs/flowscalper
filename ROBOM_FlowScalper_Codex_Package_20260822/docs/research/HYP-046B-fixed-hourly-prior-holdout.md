# HYP-046B 시간봉 K 고정 후보 독립 과거구간 검증

## 상태

- `PREREGISTERED_BEFORE_DATA_DOWNLOAD`
- 현재 보관된 `2026-04-27` 이후 결과를 본 뒤 전략 K를 설계했으므로 그 구간은 미래 OOS가 아니다.
- 아직 내려받지 않은 `2025-12-01T00:00:00Z` 이상 `2026-04-27T00:00:00Z` 미만 공개 완성 봉을 파라미터 변경 없는 독립 과거구간으로 사용한다.
- 과거구간 통과는 미래 검증을 대체하지 않으며 ACTIVE 승격 근거가 아니다.

## 고정 대상

- Registry 전략은 `HOURLY_MOMENTUM_BREAKOUT_V1`이다.
- 연구 후보 ID는 `HOURLY_MOMENTUM_BREAKOUT_24H_V1`이다.
- 1시간 완성 봉, EMA20·50 및 EMA80·200 정렬, EMA80 기울기 정렬을 사용한다.
- 24시간 모멘텀 2% 이상, 직전 20시간 고저 돌파, ADX 20 이상, 상대거래량 1.1배 이상이다.
- 다음 1시간 봉 시가 진입, 1.8 ATR 손절, TP1 2.2R 40%, TP2 4.5R 60%, 최대 36시간이다.
- 한 봉에 손절과 목표가가 동시에 닿으면 손절을 먼저 적용한다.
- 최대 동시 2개, 일 최대 4개, 재진입 대기 12시간이다.
- BASE 13bp, STRESS 25bp 왕복 비용을 차감한다.

## 독립 과거구간 합격 기준

- 표본 60건 이상.
- BASE·STRESS 기대값 모두 양수.
- BASE Profit Factor 1.15 이상.
- 승률 40% 이상, payoff ratio 1.10 이상.
- 기대값 bootstrap 95% 하한이 0보다 큼.
- 전체 기간 자연 빈도 하루 0.5~4.0건.
- 최대 한 종목의 양의 손익 기여가 전체 양의 기여의 50% 이하.

모두 통과해도 `HISTORICAL_REPLICATION_PASS_FUTURE_OOS_REQUIRED`이며 SHADOW를 유지한다. 실패하면 `NOT_PROVEN`을 유지하고 파라미터를 같은 데이터에 맞춰 변경하지 않는다.
