# ROBOM FlowScalper Codex 구현 패키지 사용법

이 압축파일은 **실제 코인 시장데이터를 로그인 없이 받아오되, 주문은 전부 프로그램 내부의 1,000 USDT 가상계좌에서 처리하는 실시간 페이퍼 트레이딩 프로그램**을 Codex가 처음부터 끝까지 구현하도록 만든 실행 지시서입니다.

## 가장 쉬운 사용방법

1. 이 ZIP을 새 폴더에 압축 해제합니다.
2. 압축을 푼 폴더 자체를 Codex 작업 폴더로 엽니다.
3. `01_CODEX_원샷_실행프롬프트_KO.txt`의 내용을 Codex에 그대로 붙여넣습니다.
4. Codex가 `AGENTS.md`, `PLANS.md`, `IMPLEMENT.md`, `docs/`, `config/`, `schemas/`를 읽고 구현을 계속하게 둡니다.
5. Codex가 계획만 작성하고 멈추면 아래 한 줄만 추가로 보냅니다.

```text
계획 승인. IMPLEMENT.md와 PLANS.md를 기준으로 구현·테스트·수정·증거작성을 완료할 때까지 다음 Wave를 자율적으로 계속 진행해. 중간 설명만 하고 멈추지 마.
```

## 사용자 계정이나 비밀번호가 필요한가?

초기 프로그램에는 필요 없습니다.

- 거래소 로그인 없음
- 거래소 API Key 없음
- OpenAI API Key 없음
- TradingView 계정 없음
- 실제 주문 없음
- 실제 입금 없음

프로그램은 Binance USDⓈ-M Futures의 **공개 시장데이터**를 기본으로 사용하고, 연결이 불가능할 경우 Bybit Linear의 **공개 시장데이터**를 대체 공급자로 사용할 수 있게 만듭니다. 한 번 시작한 실험 Run에서는 서로 다른 거래소 가격을 섞지 않습니다.

## 처음 실행할 때 보여야 하는 문구

```text
MARKET DATA: LIVE
EXECUTION: PAPER
STARTING EQUITY: 1,000.00 USDT
REAL ORDERS: DISABLED
LOGIN / API KEY: NOT REQUIRED
```

실제 공개시세 연결이 실패한 경우에는 가짜 데이터를 LIVE라고 표시하면 안 됩니다. 반드시 `FIXTURE` 또는 `OFFLINE SIMULATION`이라고 명확히 표시해야 합니다.

## 구현 결과의 목표

- 실시간 코인 수십 종목 감시
- 유동성과 거래비용을 기준으로 자동 종목선별
- 좋은 자리만 후보화
- 진입 전에 진입가·손절가·익절가·수량·최대손실 계산
- 실제 호가를 사용한 보수적 가상체결
- 진입 후 근거가 유지되는지 계속 관리
- 익절·손절·근거소멸·비상정체 중 하나로 거래 완전종료
- 차트에 진입·익절·손절선 표시
- 거래 이유와 거절 이유를 한국어로 표시
- 1,000 USDT 가상계좌 손익과 수수료·슬리피지 반영
- 거래 리플레이와 성과분석
- 실제 주문코드는 이번 버전에서 구조적으로 차단

## 중요한 기대치

이 패키지는 수익을 보장하는 프로그램을 요구하지 않습니다. Codex가 백테스트 숫자를 꾸미거나, 데이터가 부족한데 승률·확률을 임의로 만들어 표시해서도 안 됩니다. 목표는 **실제 비용과 실패상황을 포함하는 검증 가능한 연구·페이퍼 시스템**입니다.
