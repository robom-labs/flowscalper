# ROBOM FlowScalper v0.2 사용법 먼저 읽기

이 프로그램은 실제 공개 암호화폐 시장데이터를 로그인 없이 관찰하고, 모든 계획·체결·손익을 내부 1,000 USDT PAPER 계좌에서만 처리한다. 실제 주문, private API, API 키, 입금, 출금, 이체 기능은 없다.

## macOS에서 가장 빨리 실행하기

One Touch 외장하드를 사용하는 현재 설치에서는 다음 파일을 더블클릭한다.

```text
/Volumes/One Touch/ROBOM_AUTOTRADING/FlowScalper_v0.2_20260822/START_ROBOM_FlowScalper.command
```

이 파일이 전용 APFS 작업공간을 마운트하고 `ROBOM_FlowScalper.app`을 연다. 앱 대신 프로젝트 최상위의 `ROBOM_FlowScalper.command`를 더블클릭해도 된다. 종료는 열린 Terminal에서 `Control+C`를 누른다.

외장 설치가 아닌 릴리스 ZIP을 새로 푼 경우에는 다음 순서로 실행한다.

1. `ROBOM_FlowScalper.app`을 더블클릭한다.
2. 앱 실행이 제한되면 `ROBOM_FlowScalper.command`를 Control-클릭해 연다.
3. 최초 설치에 `uv`, Node.js 22.13 이상 또는 24 이상, `pnpm`이 필요하다.
4. 설치가 끝나면 브라우저의 localhost 대시보드가 열린다.

Windows에서는 `scripts\run_windows.bat`을 실행한다.

## 처음 보이는 안전 상태

프로그램은 `READY`로 열리며 시작자산은 1,000.00 USDT, 손익·수수료·슬리피지·거래는 모두 0이어야 한다. 상단에는 `PAPER`, `실제 주문 없음`, `로그인 / API 키 필요 없음`이 계속 표시된다.

`실시간 PAPER 시작`을 누르면 새 Run이 만들어진다. 공개 depth 이벤트가 실제로 검증되기 전에는 LIVE로 표시하지 않고 신규 진입을 잠근다. `오프라인 샘플 보기`는 LIVE 성과와 완전히 분리된 DEMO Run이다.

## 프로그램이 하는 일

- 공개시장 USDT 무기한선물 수십 종목을 계속 감시한다.
- 최대 50개를 wide 관찰하고 8~12개를 정밀 분석한다.
- A/B/C/D 전략을 ACTIVE·SHADOW·OFF와 LONG·SHORT 설정에 따라 평가한다.
- 진입 전에 entry, TP1, TP2, SL, 수량, 최대손실, 비용을 확정한다.
- latency 이후 실제 bid·ask 호가 깊이를 사용해 보수적으로 PAPER 체결한다.
- 현재 포지션, 실현·미실현 순손익, 수수료, 슬리피지를 실시간 화면과 원장에 연결한다.
- 저장 공개 이벤트를 같은 backend 전략·후보·체결 경로로 리플레이한다.
- 전략별 기대값, Profit Factor, 비용, drawdown, 표본상태를 표시한다.

## 중요한 안전 경계

- 자연스러운 진입신호가 없으면 전략 기준을 낮추지 않는다.
- 데이터가 부족하면 승률이나 확률을 만들지 않고 `CALIBRATING`으로 표시한다.
- 연결 끊김, sequence gap, 지연, 디스크 압박, 원장 오류, 복구 불일치는 신규 진입을 fail-closed로 잠근다.
- 120초가 지났다는 이유만으로 포지션을 강제 종료하지 않는다.
- PAPER 결과는 실제 수익이나 미래 성과를 보장하지 않는다.
