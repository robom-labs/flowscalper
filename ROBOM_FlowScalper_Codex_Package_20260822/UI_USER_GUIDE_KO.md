# ROBOM FlowScalper v0.2 화면 사용설명서

## 화면 위쪽의 고정 안전표시

모든 화면 상단에는 데이터 출처, PAPER, 실제 주문 없음, UI 연결 상태가 항상 보인다. 그 아래에는 시장데이터 상태, 내부 PAPER 실행, 시작자산, 로그인·API 키 불필요, 현재 Run ID가 표시된다.

- `LIVE DATA`는 검증된 공개시장 depth가 실제로 들어오는 상태다.
- `RECONNECTING`, `DISCONNECTED`, 검증 대기는 LIVE가 아니다.
- `OFFLINE DEMO`는 예시 기능을 보는 별도 fixture Run이다.
- `PAPER`는 모든 체결과 손익이 내부 가상계좌 결과라는 뜻이다.

## 1. 라이브

READY 상태에서는 `실시간 PAPER 시작`과 `오프라인 샘플 보기` 중 하나를 선택한다. LIVE PAPER를 누르면 1,000 USDT, 손익·비용·거래 0인 새 Run이 만들어지고 공개 데이터가 검증될 때까지 신규 진입이 잠긴다.

계좌 요약에는 현재 자산, 실현·미실현을 합친 순손익, 누적 수수료, drawdown, 데이터 지연 p95가 표시된다. 종목과 1초·5초·15초·30초·1분·3분·5분·10분·15분 시간구간을 바꾸면 backend가 저장한 실제 체결 캔들로 차트를 갱신한다.

차트는 candle, bid, ask, microprice와 현재 PAPER 포지션의 entry, TP1, TP2, SL, 체결 marker를 함께 표시한다. 종목 스캐너는 wide 유니버스의 레짐, 전략, 점수, 순 R:R, 비용을 보여준다.

현재 포지션 패널에는 계획 진입과 실제 진입, 수량과 명목가치, TP·SL, 위험예산, 최대손실, 순손익, 수수료, 슬리피지, 보유시간이 표시된다. 비상종료 버튼은 실제 주문이 아니라 내부 PAPER 청산 요청이다.

## 2. 전략 관리

네 전략 카드에서 `실전 PAPER`, `가상 관찰`, `끄기`를 선택하고 LONG·SHORT를 독립 제어한다. 전략 이름, 안정성, 지원 레짐, 한국어 설명, 현재 설정, BASE 기대값, Profit Factor, 표본상태, shadow 자산을 한눈에 볼 수 있다.

`성과·비용 상세 보기`를 펼치면 BASE와 STRESS의 표본, 승률, 기대값, Profit Factor, 수수료·슬리피지, 최대 낙폭, 권고를 비교한다. 권고는 참고용이며 전략을 자동으로 끄거나 켜지 않는다.

## 3. 거래내역

완전히 종료되어 SQLite 원장에 저장된 PAPER 거래만 표시한다. LIVE 공개시장 거래와 오프라인 DEMO를 구분하며, 진입·종료, 방향, 전략, gross PnL, 수수료, 슬리피지, net PnL, 보유시간을 확인한다.

`상세`는 수량, 초기 손절, 목표, 실제 체결값을 보여준다. `재생`은 해당 Run을 리플레이 화면에서 선택한다.

## 4. 결정적 리플레이

저장된 공개시장 Run과 선택 종목을 backend ReplayEngine에 다시 입력한다. 재생 버튼, 한 이벤트 이동, 0.5×·1×·4×·10× 속도, timeline slider로 이벤트 흐름을 살펴볼 수 있다.

backend 실행 결과에는 전체 이벤트 수, 전략 평가 수, 적격 수, 계획·거래 수, 최종 상태, 입력 checksum, 결정 경로가 표시된다. 동일 저장 입력을 두 번 실행했을 때 checksum과 결정 결과가 같아야 한다.

## 5. 성과분석

전체 표본과 전략별 BASE·STRESS를 분리한다. 기대값, Profit Factor, 비용, 최대 낙폭, 보유시간, 표본상태를 승률과 함께 본다. 30건 미만은 기본적으로 표본 수집 중이며 수익성 결론을 내리지 않는다.

`독립 shadow 가상계좌 보기`를 펼치면 전략·비용 프로필별 현재 자산, 순손익, 수수료, 슬리피지, 최대 낙폭을 확인할 수 있다.

## 6. 위험관리

거래당 위험, 최대 동시 포지션, 일간·주간 손실한도, 낙폭 잠금과 현재 안전 잠금을 표시한다. 신규 진입 일시정지·재개와 `기존 기록 보존 후 새 Run`을 제공한다.

새 Run은 기존 기록을 삭제하지 않는다. 새 실험은 다시 1,000 USDT, 손익·수수료·거래 0에서 시작한다. 물타기, 마틴게일, 피라미딩, 손절 확대는 구조적으로 금지된다.

## 7. 시스템

기본 카드에서는 데이터 연결, UI 연결, 거래소, Run, storage 상태, 인증 헤더 사용 여부를 확인한다. `고급 진단 보기`에는 event, reconnect, gap, resync, drop, queue, 지연, 실제 CPU·메모리·thread·uptime·디스크, storage guard, 원장 오류와 buffer 수가 표시된다.

전문 용어가 필요 없는 운영 판단은 기본 카드에 두고 원시 enum과 계측값은 접이식 진단에 분리했다.

## 모바일과 태블릿

일곱 화면과 핵심 기능은 데스크톱·태블릿·모바일에서 동일하다. 작은 화면에서는 표와 카드가 재배치되며 버튼과 선택 컨트롤은 최소 48px 터치 영역을 유지한다. 넓은 표는 해당 패널 안에서만 가로 스크롤하고 문서 전체는 옆으로 밀리지 않는다.

## 꼭 기억할 사항

화면의 LIVE, 전략 적격, PAPER 수익, 리플레이 일치는 실제 주문이나 미래 수익을 뜻하지 않는다. 이 프로그램은 공개시장 연구와 보수적 PAPER 실행만 제공한다.
